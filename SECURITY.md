# Security policy

## Supported versions

Security fixes are provided for the latest released version.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Include the affected version, reproduction steps, impact, and any suggested mitigation.

Do not include Codex transcripts, authentication files, API keys, or unrelated source code. Please do not open a public issue for an unpatched vulnerability.

You can expect an initial response within seven days. A fix and disclosure timeline will be coordinated based on severity and reproducibility.
